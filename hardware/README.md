# ESP32-S3 enclosure

`ESP32 Dual TypeC Case_AB.3mf` contains the enclosure variants used for bridge A
and bridge B, with role markings added to distinguish the two devices.

The enclosure is based on **ESP32-S3-DevKitC : Basic Case** by MisterBeaver on
MakerWorld. The original model page is retained as the attribution and source
reference:

https://makerworld.com/en/models/159341-esp32-s3-devkitc-basic-case

MakerWorld lists the original model under Creative Commons
Attribution-NonCommercial-ShareAlike (CC BY-NC-SA). The modified enclosure remains
subject to the applicable upstream model license; the repository's project-code
license does not replace those terms.

Modification in this repository: A/B role markings were added for the two bridge
enclosures.
